
型号：XJ-3000
版本：V2.0
发布日期：2024-01-15

变更说明：本版本对推力参数和维护周期进行了修订，请以本版本为准。

第一章 系统概述
XJ-3000 型发动机（V2.0）完成了第二代改型，额定推力提升 8%。

第二章 技术参数（V2.0 修订版）
2.1 推力参数
额定推力：3456 N          ← V2.0 更新值（原 V1.2 为 3200 N）
最大推力：4500 N
最小稳定推力：850 N

2.2 燃油规格
推荐燃油：RP-3 或 JET-A1（兼容）
燃油消耗率（额定）：0.35 kg/(N·h)    ← 效率提升

2.3 工作温度范围
工作温度：-45°C 至 +70°C

第三章 安全规定（V2.0 修订）
3.2 紧急停机
出现以下情况应立即停机：
（1）振动烈度超过 10 mm/s    ← 阈值收紧
（2）排气温度超过 750°C      ← 阈值收紧
（3）油压低于 0.35 MPa       ← 阈值收紧

第四章 维护周期（V2.0 修订）
定期检查间隔：每 60 飞行小时  ← V2.0 延长
大修周期：每 600 飞行小时
寿命限制：4000 飞行小时       ← V2.0 延长
