# 基于细粒度证据核验的私域可信问答智能体

## 架构概览

```
用户问题
   │
   ▼
┌─────────────────────────────────────────┐
│              外层调度模块                 │
│  ┌─────────────┐   ┌──────────────────┐ │
│  │  内层生成智能体  │   │  细粒度核验引擎   │ │
│  │  (RAG 初稿)  │──▶│  规则硬校验       │ │
│  └─────────────┘   │  + 语义蕴含三分类  │ │
│                    └──────┬───────────┘ │
│                           │ 成因分类      │
│              ┌────────────┼────────────┐ │
│              ▼            ▼            ▼ │
│         检索未命中     证据不足      依据不适用│
│         查询改写      扩量召回      版本过滤  │
│              └────────────┼────────────┘ │
│                      超限 → 拒答          │
└─────────────────────────────────────────┘
   │
   ▼
可追溯回答 / 溯源排查报告
```

## 核心组件

| 模块 | 说明 |
|------|------|
| `ingestion` | 文档解析、分块、元数据提取（型号/版本）|
| `retrieval` | 向量检索 + BM25 混合召回 |
| `generation` | 基于检索证据的回答生成 |
| `verification` | 细粒度核验：规则硬校验 + NLI 三分类 |
| `repair` | 差异化修复：改写/扩召/版本过滤 |
| `agent` | 调度主循环：迭代 + 拒答止损 |
| `api` | FastAPI 接口 + 前端演示 |

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置（复制后编辑）
cp config.yaml.example config.yaml

# 3. 导入示例文档
python scripts/ingest_docs.py --docs data/sample_docs/

# 4. 启动服务
python -m src.api.app

# 5. 访问演示界面
# http://localhost:8000
```

## 运行示例

```bash
# 命令行快速测试
python scripts/run_query.py --question "三号发动机的额定推力是多少？"
```

## 内网离线部署

- LLM 后端：Ollama (llama3 / qwen2.5) 或兼容 OpenAI 的本地推理服务
- 嵌入模型：`BAAI/bge-small-zh-v1.5`（离线下载）
- 向量库：ChromaDB（本地持久化）
- 零外网依赖

## 验证指标

- **事实准确率**（FactScore）：支持句子级追踪
- **分类别检出率**：三类幻觉成因分别统计
- **误拒率**：有有效证据但触发拒答的比例
- **平均迭代轮次**：修复收敛效率
- **端到端时延**：含迭代开销
